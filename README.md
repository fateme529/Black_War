# Black War

![Language](https://img.shields.io/badge/language-C%2B%2B-blue)
![Platform](https://img.shields.io/badge/platform-Windows-0078D6)
![License](https://img.shields.io/badge/license-MIT-green)

A console-based, side-scrolling helicopter shooter written in C++ — pilot a helicopter
on a text grid, dodge incoming walls, shoot down enemies for points, and save/resume your
run.

## How it works

The board is a 10x20 grid of cells drawn in the terminal. Your helicopter (`>`) sits on
the left edge and can only move up or down; walls (`#`) and enemies (`<`) scroll in from
the right toward you. Firing sends a shot (`*`) from the helicopter across the board.

- Shooting down an enemy (`*` reaching a `<`) scores a point.
- Letting your helicopter (`>`) collide with a wall or an enemy ends the run.
- There's no fixed "win" — it's a score-attack: survive and rack up points for as long
  as you can.

## Commands

Typed at the `>` prompt before/after a run (case-insensitive):

| Command | Effect                                             |
|---------|-----------------------------------------------------|
| `s`     | Start a new game                                     |
| `load`  | Resume the last saved game                           |
| `help`  | Show the command list                                |

## Controls

While a game is running:

| Key | Action                                  |
|-----|------------------------------------------|
| A   | Move the helicopter up                   |
| D   | Move the helicopter down                 |
| W   | Fire a shot                              |
| E   | Save the current game and exit           |

## Saving and loading

Pressing **E** during a run writes the board and your score to `string_array_data.bin`
and `point.bin` next to the executable. Typing `load` at the prompt reads those files
back and resumes the run from where you left off. These save files are generated by
playing the game, so they aren't tracked in this repository — a fresh checkout starts
clean, and your own save appears the first time you press **E**.

## Project structure

```
include/            # class declarations: App, helicopter, enemy, barrier, shoot
src/                 # class implementations + main.cpp entry point
Makefile             # builds all sources with g++
```

## Building and running

```bash
make
./a.exe
```

`make` compiles every file under `src/` with g++ and links them into `a.exe`. No
external libraries are required — the game only uses the standard library and
`conio.h`/`windows.h` for console input, so it's Windows-only as written.
